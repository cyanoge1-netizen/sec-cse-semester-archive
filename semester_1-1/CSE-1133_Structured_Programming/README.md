# CSE 0613 1133: Structured Programming Language

**Credit:** 3.00 Hours/Week  
**Institution:** Department of Computer Science & Engineering, Sylhet Engineering College (SEC)  
**Primary Language:** C (ANSI C / C99)

---

## 📚 Syllabus Outline
1. **Introduction to Programming & C Fundamentals:** Identifiers, keywords, data types, variables, constants.
2. **Operators & Expressions:** Arithmetic, relational, logical, bitwise, conditional operators.
3. **Control Flow:** `if-else`, `switch-case`, `for`, `while`, `do-while`, dangling-else resolution.
4. **Functions & Storage Classes:** Parameter passing (call-by-value vs. call-by-reference), recursion, static/extern variables.
5. **Arrays & Strings:** Multidimensional arrays, string manipulation, buffer handling.
6. **Pointers & Dynamic Memory:** Pointer arithmetic, `malloc()`, `calloc()`, `free()`, memory leak prevention.
7. **Structures, Unions & Enums:** User-defined types, nested structures, memory alignment.
8. **File I/O:** Text & binary file streams, error handling.
